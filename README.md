# plugipv4

Plug structured JSON ipv4 payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/plugipv4/

## Install / run

```bash
git clone https://github.com/theworker02/plugipv4.git
cd plugipv4
node src/cli.js
node --test
```
